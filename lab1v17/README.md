# Лабораторна робота №1

**Тема:** Створення першого проєкту. Класи, об’єкти, конструктори та деструктори. Середовище розробки.  
**Мета:** Ознайомитися з середовищем розробки Visual Studio Code, навчитися створювати класи та працювати з базовими елементами ООП у C# (Варіант 16: клас `SportTeam`), а також налаштувати систему контролю версій Git та публікацію проєкту на GitHub.

**Хід роботи:**  
У ході виконання роботи було налаштовано середовище Visual Studio Code з необхідними розширеннями, після чого за допомогою .NET CLI у директорії `OOP-Mukhamedchyn` згенеровано консольний проєкт `lab1vN`. У файлі `Program.cs` реалізовано клас `SportTeam` за Варіантом 16, що містить приватні поля (`name`, `coach`), публічну властивість (`PlayersCount`), конструктор і метод `PlayMatch()`. У точці входу `Main` створено 3 об'єкти цього класу та продемонстровано їхню роботу в консолі. Для репозиторію налаштовано файл `.gitignore`, зафіксовано коміт та відправлено сирцевий код у віддалений репозиторій на GitHub.
